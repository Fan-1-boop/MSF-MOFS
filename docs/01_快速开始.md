# 快速开始

在项目根目录执行 `python -m pip install -r requirements.txt`，再运行 `python run.py integrity`、`python run.py verify`。验证真实搜索环境：`python run.py paper demo --dataset hill_valley --seed 92`。

完整运行论文 Table 2/3：依次 `python run.py paper external`、`python run.py paper core`、`python run.py paper breadth`。新结果写入 `results/reproduced/paper/`。

卫星统一核验：`python run.py satellite verify`。Node.js 只对卫星实验必要。Windows 用户请使用已内置兼容线程池的外部基线实现；不要直接把旧 `/mnt/data/` 路径复制到命令中。
