# 03 MSF-MOFS 核心算法原理与源码导航

## 研究问题
多目标特征选择优化两个互相冲突的目标：分类错误与特征选择比例，得到一组帕累托非支配解。Fisher 引导改变**初始种群**而非替代 NSGA-II，目的是为演化搜索提供高辨别性特征子集的启动点。该项目还实现 SPEA2 作为载体对照。

## 核心数学步骤

**1. 单特征 Fisher 分数。** 对每个维度，用类别均值离散程度和类内方差构造打分。类内变化较小、类间变化较大则分数较高。只使用训练数据，绝不把测试标签送入排序。请读 `src/irmofs/stable_guidance.py::fisher_scores`。

**2. 多尺度种子。** 依据特征总数 D 构造若干不同大小的 Fisher Top-k 子集，按规定替换初始 Bernoulli 种群中的有限个体。原始种群中其余个体保持与 Random 初始化相同。请读 `stable_guidance.py::make_cisr_multiscale_population`。

**3. 优化器。** `src/irmofs/nsga2.py` 包含非支配排序、拥挤距离、二元竞争选择、子代生成、精英环境选择；`src/irmofs/spea2.py` 提供 SPEA2适应度与环境选择。变量名中的 `F` 常表示两目标的数组。

**4. 评估与数据隔离。** `src/irmofs/evaluator.py` 对候选子集进行缓存评估，二分类评价使用 G-mean（灵敏度与特异度的几何平均）。目标通常是 `(1-G-mean, k/D)`，均为越小越好。`environments.py` 构建不同不平衡率训练环境；保留集只用于最终效果对比。

**5. 结果选择与超体积。** `src/irmofs/selection.py` 实现多种从帕累托解中选单个方案的规则；`nsga2.py::hypervolume_2d` 实现二维最小化超体积。

## 复现实验注意
- 改动分类器、折分、种子、归一化、初始化染色体数量或者 HV 参考点都会改变问题，不可作为同一论文协议直接比较。
- 已存在的 `src/irmofs/` 算法语法树未变，中文注释是可直接读懂的辅助，不是再实现一份“近似算法”。
- 想追踪论文表格生成和现有统计检验，请读 `src/msf_repro/audit.py`、`statistics.py`、`paper_table_checks.py` 与 `docs/09_代码与论文对应关系.md`。
