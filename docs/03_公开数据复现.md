# 公开数据集复现实操教程

本章只讨论论文主体 MSF-MOFS 特征选择实验。卫星健康度案例请另见 `04_卫星应用复现.md`。

## 1. 先理解三个层级

1. **证据审计**：`python run.py paper status` 和 `python run.py paper check`，核实已打包实验结果，时间相对短，但不是重新搜索。
2. **单种子真实搜索**：`python run.py paper demo --dataset hill_valley --seed 92 --out results/reproduced/paper/demo_hill_valley_92`，实际跑 NSGA-II 与 SPEA2、MSF 与 Random 四种组合；主要用于确认环境正常，不代表表格统计。
3. **正式完整复现**：执行本章 Table 2/3、消融、Population=50 的全量命令；所有预定随机种子运行完毕后，再计算论文统计量。

安装及实验参数见根目录 `README.md` 和 `configs/frozen_protocol.json`。请从有 `run.py` 的根目录启动。

## 2. 按论文实验逐项运行

| 内容 | 单种子试跑 | 冻结协议完整运行 | 原始结果 | 新结果（默认） |

| Sparse-control，50 条 | `python run.py paper sparse --datasets colon --seeds 92` | `python run.py paper sparse` | `results/reference/sparse_control/raw.csv` | `results/reproduced/paper/sparse_control/sparse_control_raw.csv` |

## 3. 自己运行一次后查看什么

以核心数据为例：

```bash
python run.py paper core --datasets hill_valley --seeds 92 \
  --out results/reproduced/paper/table3/core_hill_valley_92
```

结束后检查：

```text
results/reproduced/paper/table3/core_hill_valley_92/
├── raw.csv                       4 条逐次搜索结果
├── summary.csv                   按优化器、初始化归纳
├── paired_msf_vs_random.csv       MSF 与 Random 成对比较
├── protocol.json                 所用协议参数
└── msf_nsga_archived_comparisons.json  有来源支持的历史 MSF-NSGA 逐种子核对
```

每个正式确认种子在一个数据集上对应 NSGA-II/Random、NSGA-II/MSF、SPEA2/Random、SPEA2/MSF 共四个单元。`msf_nsga_archived_comparisons.json` 仅适用于有独立历史基准记录的组合，不要据此声称其余三种配置已经逐值比对。

## 4. Table 3 统计与配对分析

```bash
# 直接使用已归档的 360 条完整 raw CSV
python run.py paper stats --scope nine

# 对新搜索的完整 360 条 raw CSV 进行独立统计
python run.py paper stats --scope nine \
  --input results/reproduced/paper/table3/core/raw.csv \
          results/reproduced/paper/table3/breadth/raw.csv \
  --out results/reproduced/paper/table3_new --evidence-type reproduced
```

输出包含 `paired_hv_ci_effect.csv`、HV 参考点敏感性结果和 `PROVENANCE.json` 等。统计程序不执行优化搜索。要生成正式完整 9 数据集统计，输入 CSV 必须具备对应的全部实验单元；只跑某一个种子后不可直接作为论文 Table 3 报告。

## 5. 不要混淆的三件事

- `paper status` 检查历史 `results/reference/` 中的 160/200 条覆盖；不会把你刚生成在 `reproduced` 的少量结果当成完整 360 条。
- `paper check` 输出历史 Table 2/3/消融审计状态，但其 `FULL END-TO-END REPRODUCED: False` 是原审计程序对全论文端到端证据的更严格判断，不能删除或改为 True。
- 公开数据基线、MSF 引导与卫星 V6 的冻结部署实验属于不同证据层级，论文的公开算法结果要用 `paper` 系列命令，而不是 `satellite-smoke` 或 `benchmark`。

## 6. 代码入口和协议位置

- `run.py`：公开实验顶层 `paper` 命令。
- `src/msf_repro/cli.py`：数据集、种子、输出目录、实验任务的调度。
- `scripts/public/`：真实搜索和统计支持程序。
- `src/irmofs/stable_guidance.py`：Fisher 与多尺度引导初始化；`nsga2.py` / `spea2.py`：优化器；`evaluator.py`：目标评价。
- `configs/frozen_protocol.json`：正式参数；`data/public/`：输入；`results/reference/`：原结果；`results/reproduced/paper/`：自己运行的新结果。

**完整复现需要的运行时间取决于 CPU、内存和环境，不应将快速检查等同于全实验完成。**
