# 12 卫星应用的论文结论与验证入口

## 为什么需要独立入口

卫星应用的论文结论分为**特征选择效果**、**冻结特征身份**、**运行速度**和**故障证据保留**。验证其中一项，不等于自动验证全部。

## 最快的两条命令

```bash
python run.py satellite archive       # 只读历史逐种子 CSV，重算四子系统 Table 4
python run.py satellite verify        # 在此基础上实测特征、健康联调与计时
```

扩展的实际 V8 仿真确认：

```bash
python run.py satellite verify --with-v8 --repeats 2000 --warmup 100
```

## 核心数据边界

- V6 开发数据：354 场景、7,080 窗口，可在冻结协议规定的开发/训练/验证分区内训练或选特征。
- V8 独立确认数据：411 场景、9,042 窗口，不允许用于再选择140特征。
- V8 健康确认脚本的 30+72+45 个场景及 12 条渐进退化轨迹，不等同于上述 411 场景特征验证库。
- 历史 V8 确认脚本哈希与冻结来源清单存在两处不一致。运行适配副本不应被表述为逐字节原版执行。
- 历史 40 条 Table 4 结果和本次重新运行的 40 条结果必须分别保存在 `evidence/` 与 `results/reproduced/`。

## 自动生成的报告

- `results/reproduced/satellite/verification/report.md`：人类阅读的中文结论对照。
- `results/reproduced/satellite/verification/report.json`：统计数值、测试执行状态和证据类型。
- `results/reproduced/satellite/verification/*.log`：各子任务执行日志。
- `results/reproduced/satellite/verification/benchmark/raw_timings.csv`：全部逐次微秒计时。
- `results/reproduced/satellite/verification/benchmark/summary.json`：本机版本、CPU、p95/p99 等。

**严格结论**：历史 Table 4 的记录可复算与从零跑完40组搜索是两个不同命题。只有全部重跑并检查结果后，才能宣称新环境完成了40组端到端复现。


## V6 开发与 V8 确认

V6 开发数据为 354 场景、7080 窗口，V8 确认数据为 411 场景、9042 窗口。V8 不用于重新选择140个冻结特征。
